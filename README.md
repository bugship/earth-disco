# Earth Disco

Interactive **3D Earth** in Three.js — surface, bump, specular water, city lights, clouds, Fresnel atmosphere, and a procedural starfield.

## Features

- Multi-texture Earth globe
- Cloud layer + atmospheric Fresnel rim
- OrbitControls exploration
- Starfield background

## Tech

Three.js · WebGL · JavaScript

## Run

```bash
git clone https://github.com/bugship/earth-disco.git
cd earth-disco
npx --yes serve .
```
